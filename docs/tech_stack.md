# Tech Stack Specification - CFC_Shop

## 1. Backend (.NET 8 Web API)
- Runtime: .NET 8 Web API (C#).
- ORM: Entity Framework Core 8.x.
- Database Provider: Npgsql.EntityFrameworkCore.PostgreSQL.
- API Standard: RESTful API, JSON Payload, Swagger/OpenAPI.

## 2. Database (PostgreSQL)
- Database Engine: PostgreSQL 16+.
- Database Name: cfc_shop_db.
- Core Schema (7 Tables): Roles, Users, Categories, Products, CartItems, Orders, OrderDetails.

## 3. Frontend (Next.js & React)
- Framework: Next.js 14+ (React 18+).
- Styling: Tailwind CSS.
- UI Components: Shadcn UI.
- React Hooks Focus: useState, useEffect, useCallback, useMemo.
